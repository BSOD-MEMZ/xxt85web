# 手账主题 · Sticker Book

2026-09 新增的第三套主题。与默认的 Vista 拟物完全割裂，改用纸感卡片 + 贴纸的视觉语言。

| 文件 | 作用 |
|---|---|
| `modern-sticker.css` | 主题样式，约 2900 行，**自包含全站组件** |
| `js/modern-sticker.js` | 配套交互脚本（由 `theme-loader.js` 自动加载） |
| `js/modern-sticker-icons.js` | 图标 sprite（由 `.workbuddy/tmp/gen-icons.js` 生成，产物提交） |

启用方式：个性化面板的「切换主题」循环到它，或首次访问时在引导对话框里选「手账贴纸」。

---

## 一、硬性约束

这几条是站长定的，不是建议：

1. **禁止 `backdrop-filter` / 毛玻璃。** `box-shadow` 可以用。
2. **字体只用本机的 `msyh`。** 不下载任何字体文件，零外部请求。
3. **默认主题零影响。** 所有改动只在 `theme === 'modern-sticker.css'` 时生效。
4. **不加无用的描述性文本。** 情绪靠动效和质感表达，不靠嘴。

## 三、视觉语言

### 卡片 = 贴在本子上的纸片

`.window` 用 `::before` 贴一条胶带。**每张卡片的胶带位置、角度、颜色都不同**（`.sidebar .window:nth-child(n)::before`），刻意的错落是手账感的关键——整齐划一反而像模板。

```css
.window::before {
    content: "";
    position: absolute;
    top: -9px; left: 26px;
    width: 64px; height: 18px;
    background: var(--tape);
    transform: rotate(-2.5deg);
}
```

### 标题栏 = 一枚小方块 + 虚线

不再有拟物的渐变条，改成「色块标记 + 文字 + 底部虚线」，颜色与顶上的胶带同色系。

### 背景 = 主题自己的纸面

**不引用任何壁纸图片**。`body::before` 用不透明的纸色 + 三处彩色光晕 + 极淡网格铺满。

> 早期版本是「壁纸 + 半透明纸色罩」，站长眯眼看仍然认出是旧站的 Vista 构图——那层罩子透出来的 18% 就是问题所在。彻底换成不透明纸面后才干净。

原本的「切换背景」按钮在新主题里改为切换 5 套纸面色调（`html[data-xxt-bg="0..4"]`）。

### 顶栏合并

站名在左、导航居中、搜索框贴右，收进一行。

做法是 `.navbar` 绝对定位 + `pointer-events` 分层（外层 `none`、内层 `auto`），**不改动任何 HTML 结构**，所以切回旧主题时旧样式照常生效。

### 导航项

纯文字、无背景无描边，悬停时底下浮出一条短下划线（`::after` 的 `scaleX(0→1)`）。

## 五、交互规范

| 交互 | 触发 | 反馈 |
|---|---|---|
| **贴纸抬起** | 指针在卡片上移动 | 按指针纵向位置轻微上浮（1.5–3px）。**不做旋转**——试过，太夸张 |
| **标签盖章** | 点击栏目筛选 | `scale(1.16)` → `0.94` → 1，340ms 回弹 |
| **纸角掀页** | 列表项悬停 | 右上角出现一个三角纸角 |
| **卡片入场** | 首次铺卡片 | 按 45ms 错峰上浮淡入。**只播一次**，筛选重渲染不重复 |
| **撕掉组件** | 点侧栏小窗口的关闭圆点 | 轻抬放大 → 侧倾 7° 缩小淡出（340ms）→ 加 `window-hidden`，同时弹出「撤销」条 |
| **贴回组件** | 点「撤销」 | 反向动画：从 `scale(.86) rotate(-5°)` 弹回原位 |
| **复制成功** | 点文章页代码块的复制按钮 | 方框缩小消失 → 绿勾弹出 → 淡出还原（约 1.3s） |
| **荧光笔选中** | 选中文本 | 半透明胶带黄底 |
| **手绘焦点框** | 键盘 Tab | 虚线圆角框，比默认 outline 更醒目 |
| **背景视差** | 页面滚动 | 15 个几何形按 0.08–0.26 的不同速度分层位移 |

设计原则（来自 `microinteractions` 框架）：

- 反馈必须在 **100ms** 内出现
- 反馈强度匹配事件重要性——小动作给小反馈
- **只保留 1–2 个「签名时刻」**。本主题的是「卡片错落入场」和「活的进度条」，其余一律克制
- 每个动效都要有理由，纯装饰的不加

## 六、实现技巧

### 1. CSS 变量能穿透 `<use>` 的影子边界

`<use>` 引用的 sprite 内容无法被外部 CSS 选中，**但 CSS 变量可以继承进去**。所以要做「可换色的自绘图标」，在 symbol 里写 `fill="var(--xxt-x, 默认色)"`，外部给宿主元素设变量即可。

这是关闭圆点能五色切换的原因。

### 2. 两套主题复用一个组件，靠挂站点原有的类

选择对话框的取消/确定按钮直接挂 `.vista-btn` / `.vista-btn-primary`：Vista 下自动是灰渐变黑字，手账下自动变成纸色按钮，**不用写一行主题判断**。

### 3. 动画用 `backwards`，不要用 `both`

入场动画若用 `animation-fill-mode: both`，结束态（`transform: none`）会一直生效，**盖住 `:hover` 的 transform**。用 `backwards` 只在延迟期保持起始态，播完立刻交还元素自身样式。

### 4. 视差与漂浮必须分两层

```html
<div class="xxt-deco">            <!-- 外层：JS 写 transform 做视差 -->
  <span class="xxt-deco-shape">   <!-- 内层：CSS animation 做漂浮旋转 -->
</div>
```

两者都用 `transform`，挤在一个元素上会互相覆盖。

### 5. 顶栏的 `pointer-events` 分层

`.navbar` 覆盖整个顶栏宽度，靠 `pointer-events` 保证不挡交互：外层 `none`，`.navbar .wrap` 恢复 `auto`。

## 八、文章页的差异

文章页的 DOM 与顶层页毫无重合，`modern-sticker-article.css` 是一份**独立自包含**的样式，
不共享 `modern-sticker.css` 的任何选择器。同一套设计语言在三处的落地方式：

| 元素 | 顶层页 | 文章页 |
|---|---|---|
| 背景 | 纸面 + 三色光晕 + 淡网格 | **只留一处顶部暖色光晕**——阅读页要安静，网格线一直在视野边角晃很累 |
| 封面 | 无 | 照片降饱和当底纹，压一层 45° 斜纹 + 纸色纱罩；标题**无底色**直接压在照片上，靠纸色描边 + 投影保证可读，下方一条珊瑚色短横线收尾 |
| 代码块 | 无 | 贴纸标题栏 + 复制按钮（三段反馈） |
| 关闭圆点 | 侧栏小窗口，五色轮换 | 图片查看器 + UAC 对话框，红色 |
