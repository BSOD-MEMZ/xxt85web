为什么是它

三件别处买不到的事

01

为教室里的那块屏而生

不是把手机音游塞进一个窗口，而是从触摸、分辨率到输入延迟，全部按班级大屏重做了一遍。

  • 原生 Windows 触摸。希沃那块红外屏直接就能吃，多指同时判定，不用装任何映射软件，也不用老师帮忙切投影模式。
  • 12 轨真全键位。键盘 Z S X D C V G B H N J M、鼠标左右键、触屏多指 —— 三种输入共用同一条判定路径，难度不会因为换设备而变。
  • 大屏不糊。全屏、高 DPI、4K 缩放下按物理像素重排，不会像某些模拟器那样糊成一团。
  • 老机器也扛得住。没有 Electron、没有引擎，整包带资源 6.9 MB，几年前的赛扬一样稳。
  • 全屏不弹输入法候选框，任务栏按钮上跑进度条，媒体浮层显示曲名与进度（Win10+）。
02

同一台电脑，就是一台街机柜

不用网络、不用服务器、不用配 IP —— 一台机器多开几个窗口，同学就是你的对手。

  • 同机多人。设置里勾上「多人游玩」，之后每双击一次 exe 就是一个新座位；有几个人就开几个窗口。
  • 共享内存总线。各窗口共用同一条曲目时间轴，实测窗口间偏差中位 3.4 ms / 最差 6.7 ms，听感上就是同一台机。
  • 看得见谁在房里。选曲界面左下角有房间胶囊，演奏时右侧实时并排队友分数条，谁掉连一眼就知道。
  • 房主一按开始，一屋子同时震。课间十分钟可以开三局，输的人负责擦黑板。
03

手感是照着官方一比一调的

谱面解析、判定窗口、结算页、选曲页 —— 不是「像」，是对着原作一项一项对出来的。

  • SUS 谱面原生解析，12 轨全部音符类型支持：tap / hold / flick / trace / critical。
  • 判定窗口内置三档预设，其中「标准」就是官方那套数值（Perfect 40 / Great 90 / Good 140 ms）；出厂默认的「宽松」是把官方各档放宽 30 ms，手感不够也能自己拖滑杆。
  • 长条尾判是「松手判定」。结束前在容错窗口内松手按距离给 Perfect / Great / Good，一直按到底同样算 Perfect，只有明显提前松手才会断连。
  • Flick 严格方向校验。左右方向必须真的甩出来，键盘按键只能产生向上 flick（不想较真可以在设置里把 Flick 视作 Tap）。
  • trace 按「覆盖」判定而不是按「点」：手指按住那条轨道就是 Perfect，没有尾判，头也不用重新点 —— 和官方规则一致。
  • 结算与选曲逐项还原：RESULT 字样、等级评价、NEW RECORD、EXP、判定明细；选曲页的卡面、难度配色、谱面等级指示、清 / Full Combo 遮罩。

常见问题

你可能想问

为什么打开之后一首歌都没有？

仓库出于版权原因不自带谱面与音频。打开附带的 chartdl.exe 把喜欢的曲子下下来，列表就有了。

手柄能打歌吗？

不能，手柄只负责菜单：方向键或左摇杆选歌换难度，A / START / Y 进入、开设置、重扫，B / BACK 退回。12 轨的东西手柄确实打不了，这是有意的。

键盘打不出左右 flick？

一个键没有方向，键盘只能发向上 flick；左右方向必须用鼠标或触摸甩出来。触屏上垂直滑动不好触发的话，可以在 设置 → 判定 里打开「Flick 视作 Tap」。

长条什么时候会断？

尾判是松手判定：结束前在容错窗口内松手，按距离给 Perfect / Great / Good；一直按到底同样是 Perfect。只有明显提前松手才算断连，窗口大小在 设置 → 判定 → 长条容错 里调。

双击没反应 / 提示缺 DLL？

SDL2.dll 必须和 cppsekai.exe 放在同一个目录。日志写在当前工作目录的 cppsekai.log，出问题先看它最后几行。

能跑在 Linux / macOS / 手机上吗？

只做 Windows 原生 —— 平台层用到了 Win32 的媒体会话、任务栏进度和命名共享内存。想看网页版可以去上游 sekai-mmw-preview-web。

它会联网吗？会上传什么东西吗？

游戏本体没有任何网络代码。只有 chartdl.exe 下载谱面时会联网，也不上传任何东西。
