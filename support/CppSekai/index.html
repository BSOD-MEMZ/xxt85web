班级大屏

Classroom

为教室里的希沃而生

不是把手机音游塞进一个窗口，而是从触摸、分辨率到输入延迟，全部按班级大屏重做了一遍。

  • 原生 Windows 触摸。希沃那块红外屏直接就能吃，多指同时判定，不用装任何映射软件。
  • 12 轨真全键位。键盘、鼠标左右键、触屏多指 —— 三种输入共用同一条判定路径。
  • 大屏不糊。全屏、高 DPI、4K 缩放下按物理像素重排，不会糊成一团。
  • 老机器也扛得住。没有 Electron 和引擎，整包带资源 6.9 MB，几年前的赛扬一样稳。
  • 系统集成。任务栏按钮上跑进度条，SMTC 加成，可接入 ClassIsland 显示曲目进度。

课间娱乐

Party

一台电脑，就是一排中二（？

不用网络、不用服务器、不用配 IP —— 一台机器多开几个窗口，在班上和同学拼机。

  • 同机多人。设置里勾上「多人游玩」，之后每双击一次 exe 就是一个新座位；有几个人就开几个窗口。
  • 共享内存总线。各窗口共用同一条曲目时间轴，实测窗口间偏差 中位 3.4 ms / 最差 6.7 ms，听感上就是同一台机。
  • 看得见谁在房里。演奏时右侧实时并排队友分数条，谁掉连一眼就知道。

对齐官方

Fidelity

手感是照着官方一比一调的

谱面解析、判定窗口、结算页、选曲页 —— 不是「像」，是对着原作一项一项对出来的。

  • SUS 谱面原生解析，12 轨全部音符类型支持：tap / hold / flick / trace / critical。
  • 判定窗口内置三档预设，其中「标准」就是官方那套数值（Perfect 40 / Great 90 / Good 140 ms）；出厂默认的「宽松」是把官方各档放宽 30 ms。
  • 长条尾判是「松手判定」。结束前在容错窗口内松手按距离给 Perfect / Great / Good，一直按到底同样算 Perfect。
  • Flick 严格方向校验。左右方向必须真的甩出来，键盘按键只能产生向上 flick。
  • trace 按「覆盖」判定而不是按「点」：手指按住那条轨道就是 Perfect，没有尾判，头也不用重新点。
  • 结算与选曲逐项还原：RESULT 字样、等级评价、NEW RECORD、EXP、判定明细；难度配色、谱面等级指示、清 / Full Combo 遮罩。
